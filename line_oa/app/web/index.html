查詢通知對象

請依下列步驟設定通知對象：

  1. 先在「總覽」完成 LINE 登入，按「手動測試連線」確認狀態為 CONNECTED。
  2. 第一次使用請按下方「重新整理」，從 LINE 載入最近的聊天聯絡人。需要找特定對象時，可輸入名稱再搜尋。
  3. 找到對象後按「設為別名」，設定 1–32 字元的小寫英文字母、數字、底線或連字號，例如 home。必須設定別名，才能發送通知。
  4. 確認對象出現在「允許的收件者別名」，再到「發送測試」選取別名測試。Home Assistant 的 who 也填入這個別名，例如 home。

找不到對象時，請先讓對方在 LINE 與此官方帳號聊天，再按「重新整理」。此處顯示後台聊天聯絡人，並非全部好友；名稱相同時請核對 Web Chat ID。
